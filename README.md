# Balance Quest · มนตราแห่งสมดุล

เกมเว็บภาษาไทยสำหรับ ม.1 นักเรียนหยิบเครื่องหมายและตัวเลขเอง ตาชั่งตอบสนองตามผลต่างและจัดรูปเมื่อการดำเนินการสะสมทั้งสองฝั่งสมมูลกัน เกมตรวจคำตอบโดยแทนค่าในสมการเดิมก่อนจบภารกิจ

## เริ่มใช้งาน

ใช้ Node.js 20.19 ขึ้นไปในสาย 20 หรือ 22.12 ขึ้นไป และเบราว์เซอร์รุ่นที่รองรับ JavaScript BigInt

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดง เช่น http://localhost:5173 ก่อนเล่นครั้งแรก เกมจะเปิด **ตั้งค่ากล้อง** ให้กด **เปิดกล้อง → อนุญาต → ใช้กล้อง** จากนั้นจึงเข้าสู่โจทย์ การเล่นครั้งต่อไปใช้เมาส์เป็นทางเลือกได้ ดนตรีเริ่มบนการโต้ตอบครั้งแรกที่เบราว์เซอร์อนุญาต

เมื่อแก้สมการจนได้ค่า x เกมแทนค่าในสมการเดิมให้อัตโนมัติ กด **ข้อต่อไป** หรือ **ดูผลและวิธีทำ** โหมด **แข่งจับเวลา** ใช้เวลาที่เลือกทั้งรอบ (1–60 นาที) มีคลังร่วม 360 ข้อ ระดับละ 60 ข้อ

หลังเปิดกล้อง ให้กด **เริ่มปรับเทียบ** แล้วบันทึกตำแหน่งนิ้วชี้ซ้าย ขวา บน และล่างเท่าที่ขยับได้สบาย ขณะเล่นเป้าสีฟ้าใช้สำหรับชี้ และเป้าสีทองแสดงว่าหยิบวัตถุได้แล้ว

บน Windows ดับเบิลคลิก [Open-Balance-Quest.cmd](Open-Balance-Quest.cmd) เพื่อเปิด Production Build ผ่านเบราว์เซอร์เริ่มต้นที่ `http://127.0.0.1:4173/` หากไฟล์เริ่มเซิร์ฟเวอร์เอง ให้เปิดหน้าต่างคำสั่งค้างไว้ระหว่างเล่น

หากหน้าพรีวิวในแอปปฏิเสธกล้อง ให้คัดลอกที่อยู่เกมไปเปิดใน Chrome หรือ Edge โดยตรง แล้วกด **ตั้งค่ากล้อง → เปิดกล้อง → อนุญาต** สิทธิ์กล้องของ `127.0.0.1` และ `localhost` หรือคนละพอร์ตเป็นคนละรายการ

```bash
npm run build
npm run preview
npm run test
npx playwright install chromium
npm run test:e2e
```

บน Windows สามารถใช้ Direct3D 11 สำหรับชุดทดสอบ Playwright ได้โดยตั้ง `$env:BALANCE_QUEST_RENDERER = 'd3d11'` ใน PowerShell ก่อนรัน `npm run test:e2e`

`npm run build` ตรวจ TypeScript และสร้าง `dist/` พร้อมไฟล์กล้อง ฟอนต์ และประกาศสัญญาอนุญาต ใช้ `npm run preview` ตรวจไฟล์ที่สร้างผ่านเว็บเซิร์ฟเวอร์ เมื่อติดตั้งบนโฮสต์ ให้นำเนื้อหาใน `dist/` ไปเสิร์ฟแบบ static ผ่าน HTTPS หากเปิดผ่าน IP ในห้องเรียนต้องใช้ HTTPS เพื่อเข้าถึงเว็บแคม ส่วน `localhost` ใช้ HTTP ได้ เปิดผ่านเว็บเซิร์ฟเวอร์เพื่อให้ Worker และโมเดลโหลดได้

## เผยแพร่บน Cloudflare Pages

สำหรับโปรเจกต์ Cloudflare Pages ที่เชื่อม Git ให้ใช้สาขา `main` ของ repository นี้ ตั้ง Build command เป็น `npm run build` และ Build output directory เป็น `dist` สำหรับโปรเจกต์ที่ใช้ Direct Upload ให้สร้าง `dist` แล้วส่งเข้าชื่อโปรเจกต์เดิมด้วย Wrangler บัญชีที่ใช้ต้องมีสิทธิ์ deploy โปรเจกต์นั้น [เอกสาร Cloudflare Pages](https://developers.cloudflare.com/pages/get-started/direct-upload/)

[GitHub Actions](.github/workflows/ci.yml) ตรวจเทสต์และ build ของซอร์สก่อนใช้ไฟล์ไปเผยแพร่ที่ Cloudflare

## Asset และการทดสอบประสิทธิภาพ

`npm run assets` ตรวจ SHA-256 ของโมเดลที่อยู่ในโครงการและคัดลอก Worker runtime, WASM และ License จาก dependency ที่ล็อกไว้ คำสั่งนี้ทำงานใน `postinstall` และก่อน Build ตาชั่ง ฉาก และผิววัตถุสร้างจากโค้ด Three.js โดยตรง ส่วนเสียงสังเคราะห์ด้วย Web Audio

รัน `npm run preview -- --port 4173` แล้วรัน `npm run perf` จากอีกเทอร์มินัลเพื่อวัด rAF ค่า p95 จากปล่อยเมาส์ถึงมุมเปลี่ยน และอัตราเฟรม MediaPipe จากวิดีโอจำลอง ตั้ง `BALANCE_QUEST_RENDERER=d3d11` เพื่อวัดด้วย ANGLE Direct3D11 บน Windows ผลบันทึกไว้ใน `test-results/performance-*.json`
