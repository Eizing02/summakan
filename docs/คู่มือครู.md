# คู่มือครู · มนตราแห่งสมดุล

## เตรียมบทเรียน

1. เปิด Balance Quest ในเบราว์เซอร์บนเครื่องที่ต่อโปรเจกเตอร์ กดไอคอนเต็มหน้าจอที่มุมบน
2. ใช้เมาส์ได้ทันที หากใช้เว็บแคม ให้เลือก **ตั้งค่ากล้อง → เปิดกล้อง** และอนุญาตในเบราว์เซอร์
3. เลือกมือที่ใช้ วางมือตรงกลางภาพแล้วกด **เริ่มปรับเทียบ** ชี้ให้ครบสี่มุมและฝึกหนีบกับคลายที่วงกลาง ปรับความไวหรือขนาดพื้นที่ตามช่วงที่นักเรียนเคลื่อนไหวสะดวก
4. ใช้ **โหมดครู** เพื่อเลือกโจทย์จากคลัง สุ่มตามระดับ หรือเพิ่มสมการของตนเอง ใช้ลูกศรจัดลำดับแล้วกด **เริ่มชุดกิจกรรม**
5. ตั้งค่า POE คำใบ้ เสียง การจับเวลา และค่าผลต่างก่อนเริ่มกิจกรรม ใช้ **ตั้งค่า** บนเมนูหลักเพื่อเลือกระดับกราฟิกหรือโหมดลดการเคลื่อนไหว

## เล่นหนึ่งรอบ

หยิบเครื่องหมายและวางบนจานซ้ายหรือขวา แล้วหยิบตัวเลขหนึ่งหลักมาวางต่อ เมื่อวางตัวเลขครบ ตาชั่งจะเคลื่อนทันที หยิบจากคลังได้หลายครั้ง หากต้องการคูณด้วย −1 ให้หยิบ **× → − → 1** วางบนจานเดียวกันตามลำดับ คูณหรือหารมีผลกับนิพจน์ทั้งฝั่ง

- **กล้อง** ใช้นิ้วชี้เลื่อนเคอร์เซอร์ หนีบนิ้วโป้งกับนิ้วชี้เพื่อหยิบ แล้วคลายนิ้วที่จุดใดก็ได้ในกรอบฝั่งซ้ายหรือขวาที่สว่างขึ้น
- **เมาส์หรือจอสัมผัส** ลากแล้วปล่อย หรือกดเลือกวัตถุแล้วกดในกรอบฝั่งที่จะวาง
- **คีย์บอร์ด** กด Tab ไปที่วัตถุ ใช้ Enter เลือก แล้วไปที่จานและกด Enter วาง กด Escape เพื่อยกเลิกการหยิบ
- **นำคำสั่งออก** ลากป้ายคำสั่งบนจานกลับเข้าคลัง หรือเลือกป้ายแล้วกด **คืนเข้าคลัง** ใช้ **ย้อนกลับ** เพื่อคืนสถานะก่อนการกระทำล่าสุด

เมื่อทั้งสองฝั่งมีผลสะสมสมมูล ระบบจะจัดรูปเอง ตัวอย่างเช่น ใช้ +3 ฝั่งหนึ่ง และ +1 สามครั้งอีกฝั่ง ค่า x ต้องตรวจด้วยการพิมพ์จำนวนเต็มหรือเศษส่วนในหน้าตรวจคำตอบ

## จัดกิจกรรม POE

| ช่วง | กิจกรรม |
| --- | --- |
| คาดการณ์ | ถามว่าใส่ +3 ฝั่งเดียวแล้วจานใดต่ำกว่า ให้นักเรียนอธิบายก่อนลงมือ |
| สังเกต | ให้ผู้ควบคุมใส่ +3 ฝั่งหนึ่ง แล้วเติม +1 ทีละครั้งอีกฝั่ง ให้ผู้บันทึกจดสิ่งที่เห็นในแต่ละครั้ง |
| อธิบาย | ให้ผู้ตรวจสอบอธิบายว่าทำไมขั้นตอนที่เขียนต่างกันถึงสมมูลกัน ลองเปรียบเทียบกับกรณี ×2 กับ +2 บนค่าร่วม 2 |
| นำไปใช้ | ให้แต่ละกลุ่มเขียนวิธีแก้โจทย์ใหม่บนกระดาษ ระบุการดำเนินการที่ทั้งสองฝั่งและแทนค่าตรวจ |

แบ่งหน้าที่เป็นผู้ควบคุม ผู้วางแผน ผู้บันทึก และผู้ตรวจสอบ หมุนเวียนบทบาททุกข้อ คะแนนควรสะท้อนเหตุผลและการตรวจคำตอบ เปิด **ผลประเมินในเครื่อง** จากโหมดครูเพื่อดูโจทย์ที่ทำเสร็จและส่งออก CSV หน้าผลของแต่ละภารกิจมี **พิมพ์วิธีทำ**

## เมื่อมีปัญหา

- หากหน้าพรีวิวในแอปปฏิเสธกล้อง ให้เปิดที่อยู่เกมใน Chrome หรือ Edge โดยตรง กด **ตั้งค่ากล้อง → เปิดกล้อง → อนุญาต** หากเคยเลือกบล็อก ให้เปลี่ยนสิทธิ์กล้องจากไอคอนข้างแถบที่อยู่แล้วโหลดหน้าใหม่
- กล้องทำงานต่อเมื่อดูผลหรือไปโจทย์ถัดไป กดไอคอนปิดกล้องเพื่อหยุด และใช้ **ตั้งค่ากล้อง** เพื่อเปิดใหม่ได้จากหน้าผลลัพธ์หรือระหว่างเล่น
- หากเคอร์เซอร์เคลื่อนยาก ลองเพิ่มแสง ลดคนที่อยู่ในกรอบกล้อง และปรับพื้นที่กับความไวอีกครั้ง
- หากฉากเคลื่อนไหวช้า ให้เลือกกราฟิก **ต่ำ** หรือ **ตาชั่ง 2 มิติ** การคำนวณสมการใช้กติกาเดียวกัน
- ก่อนใช้กับนักเรียนทั้งห้อง ให้ทำตาม [แนวทางทดสอบกล้องในห้องเรียน](CLASSROOM_CAMERA_PROTOCOL.md)
